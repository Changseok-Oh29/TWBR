# 초기 모델의 가정 및 확인 사항

현재 구현의 기준과 검증 기록입니다. 예정 작업과 완료 기준은 [다음 작업](roadmap.md)을 참고하세요.

## 현재 기준

- 입력 파일: `2WL_V3_Assem_v2/urdf/2WL_V3_Assem_v2.urdf`
- 현재 URDF의 질량·무게중심·관성값을 그대로 사용해 초기 모델링을 시작합니다.
- URDF에 기재된 13개 링크의 질량 합계는 약 4.949 kg입니다.
- 사용자는 추가 장착 부품 때문에 실물의 무게가 더 클 것으로 예상합니다. 실측 총질량과 누락 부품은 아직 확인하지 않았습니다.
- 초기 모델은 계산 및 구조 검토용이며, 실물의 물성 검증이 끝난 모델은 아닙니다.
- 사용자가 지정한 연구 상태는 주행 바퀴 두 개만 지면에 접촉해 균형을 유지하는 상태입니다. 캐스터는 지면과 떨어져 있어야 합니다.

## 파일 점검 결과

- 링크 13개, 관절 12개: revolute 6개, continuous 6개.
- 모든 링크에 질량, 무게중심, 관성 텐서가 있습니다.
- 관성 텐서는 기본적인 양의 정부호 및 주관성모멘트 삼각부등식 조건을 만족합니다. 이는 실물과 일치한다는 의미는 아닙니다.
- URDF가 참조하는 STL 파일 13개가 모두 존재합니다.
- Pinocchio 4.1.0에서 고정 베이스 및 부유 베이스 모델 로딩과 동역학 계산을 실행했습니다.

## 초기 계산 검증 (2026-11-11)

- Python 3.14.7 / NumPy 2.5.4 / Pinocchio 4.1.0, 프로젝트 전용 `.venv` 사용.
- 부유 베이스 `nq=25`, `nv=18`; 고정 베이스 `nq=18`, `nv=12`.
- 계산 기준: `pin.neutral(model)`, 일반화 속도 0, 월드 중력 `[0, 0, -9.81] m/s²`.
- 전체 질량: 4.949052425 kg. 영점 자세의 전체 무게중심: 약 `[-0.045053, -0.000651, -0.044132] m` (월드 좌표계).
- 고정 베이스의 전체 질량·무게중심 보고에는 고정된 몸체의 관성 정보도 포함합니다.
- 양쪽 모델의 영점 자세 및 추가 표본 자세에서 질량행렬의 양의 정부호성을 확인했습니다.
- 각 베이스 방식의 추가 표본 3개에서 `M(q) @ a + h(q,v)`와 RNEA 역동역학 결과가 수치 허용오차 내에서 일치했습니다.
- 속도 0에서 `h(q,0) = g(q)`임을 확인했습니다.
- 이는 구현의 수치적 일관성을 검증한 결과이며, 실제 로봇의 물성이나 균형 유지 가능성을 검증한 것은 아닙니다.

## 모델 구현 및 실물 적용 전에 확인할 항목

- `left_upper_link`, `right_upper_link`가 실제로 다리와 폐루프를 이루는지 확인합니다. 현재 URDF에서는 몸체에 연결된 별도 가지입니다.
- 실제 모터가 구동하는 관절과 수동 관절을 구분합니다.
- 균형·주행 모델은 현재 기본값인 부유 베이스를 사용합니다. 고정 베이스는 몸체가 공간에 고정된 비교용 모델이며 지면 접촉을 대신하지 않습니다.
- 두 주행 바퀴의 지면 접촉과 구름 조건을 추가하고, 캐스터가 떠 있는지 확인해야 합니다.
- 실측값 확보 후 추가 부품의 질량과 장착 위치를 확인하고, 해당 링크의 질량·무게중심·관성을 보정합니다.

## 1단계: 시각화 검증 (2026-11-11)

- MeshCat 0.3.2를 사용해 실제 STL 13개와 전체 무게중심·지면 투영점을 표시했습니다.
- 기본 표시는 부유 베이스의 영점 자세를 z 방향으로 0.35 m 옮긴 형상 검토용 자세입니다. 접촉 및 균형 해를 구한 자세가 아닙니다.
- `left_shoulder_joint`를 -10°로 설정했을 때 왼쪽 바퀴 위치가 변하고 오른쪽 바퀴 위치는 유지됨을 확인했습니다.
- 연속 회전 관절 각도 변경 시 구성 벡터의 정규화가 유지되며, shoulder의 URDF 범위를 벗어나는 명령은 거부됩니다.
- 독립 관절 조작은 URDF의 트리 구조만 따릅니다. 실제 폐루프 연결 여부와 이에 따른 연동 관계는 사용자 확인이 필요합니다.
- `outputs/robot_preview.html`에 독립 실행 가능한 3D 장면을 저장하고, Chrome에서 렌더링한 초기 화면을 `outputs/robot_preview.png`에 저장했습니다.
