# 다음 작업

목표는 **주행 바퀴 두 개만 지면에 접촉한 상태에서 균형을 유지하는 모델 기반 제어**입니다.
기본 제어를 검증한 뒤 학습으로 모델 오차를 보완합니다. 아래 항목은 예정 작업이며 아직 구현되지 않았습니다.

## 1. 실제 기구와 구동 관계 확인 — 바로 다음 작업

- [ ] `upper_link`와 다리 사이에 실제 폐루프 연결이 있는지 확인하고, 있다면 연동 제약을 정의한다.
- [ ] 실제 구동 관절과 수동 관절을 구분한다.
- [ ] 모터 명령 방식(토크/속도/위치), 감속비 및 사용 가능한 제한값을 정리한다.
- [ ] 바퀴 반지름·회전축·관절 영점과 방향을 확인한다.

**완료 기준:** 모델의 관절 운동이 실제 기구와 일치하고, 어떤 관절에 어떤 입력을 줄 수 있는지 명확하다.

## 2. 두 바퀴 접촉 자세와 정지 평형

- [ ] 평평한 지면 `z = 0`에 주행 바퀴 두 개가 닿는 자세를 계산한다.
- [ ] 캐스터 및 다른 부품의 지면 간격과 관절 제한을 확인한다.
- [ ] 접촉 위치, 전체 무게중심, 지면 투영점을 3D 뷰어에 표시한다.
- [ ] 실제 구동 관계를 반영해 정지 평형에 필요한 토크와 접촉력을 계산한다.

**완료 기준:** 기구·접촉 조건을 만족하고, 힘·모멘트 평형과 접촉력·마찰·토크 조건을 확인한다.
정지 평형의 존재가 동적 안정성을 보장하지는 않는다.

## 3. 접촉 동역학과 시간 적분

- [ ] 초기에는 접촉이 유지되는 평지·무미끄럼 구름을 가정한다.
- [ ] `M(q)`, `h(q,v)`에 접촉 및 필요한 폐루프 제약을 결합해 가속도와 접촉력을 계산한다.
- [ ] 상태를 시간 적분하고, 계산된 운동을 뷰어에서 재생한다.
- [ ] 관통·구속 오차와 접촉 이탈·마찰 한계 위반 여부를 기록한다.

**완료 기준:** 입력과 상태에 따른 운동을 재현하고, 가정이 깨지는 상태를 검출할 수 있다.

## 4. 첫 균형 제어기

- [ ] 다리 자세를 유지할 수 있는 조건을 정하고, 작은 앞뒤 기울어짐의 회복부터 다룬다.
- [ ] 평형점 부근의 모델과 제어 가능성을 확인한 뒤 LQR 등 기본 제어기를 검토한다.
- [ ] 제어 전후의 기울기, 바퀴 이동, 토크, 접촉력을 비교한다.

**완료 기준:** 정한 초기 기울기·입력 제한 안에서 균형 회복을 반복 검증한다.
구체적인 시험 범위는 모델과 구동 제한을 확인한 뒤 정한다.

## 5. 물성 보정과 학습 확장

- [ ] 총질량과 추가 부품의 장착 위치를 측정해 질량·무게중심·관성을 보정한다.
- [ ] 질량·무게중심·마찰 등의 오차와 외란에 대한 기본 제어기 성능을 평가한다.
- [ ] 실물 적용 전 센서 상태 추정, 구동 인터페이스 및 입력 제한을 연결·검증한다.
- [ ] 남는 오차에 대해 모델 오차 학습 또는 제어 입력 보정을 검토한다.
- [ ] 동일한 시험 조건에서 기본 제어기와 학습 결합 제어기를 비교한다.

**완료 기준:** 학습이 개선하는 대상과 평가 지표가 명확하고, 기본 제어기 대비 효과를 확인한다.
물성 측정은 앞선 단계와 병행할 수 있으며, 실물 적용 전에 반영한다.
